## Featured Projects

### [Python ETL Pipeline](https://github.com/tallal85/python-etl-pipeline)
A production-style **Extract → Transform → Load** pipeline built with Python, pandas, SQLAlchemy, and PyArrow.
- Modular package structure with CLI orchestration (`argparse`)
- Enriches raw sales data with temporal features, profit margins, and revenue per unit
- Loads to **SQLite** and exports **Parquet** files for downstream analytics
- **Stack:** Python · pandas · SQLAlchemy · PyArrow

### [Retail Sales EDA & ML](https://github.com/tallal85/retail-sales-eda-ml)
End-to-end **Exploratory Data Analysis** and **Machine Learning** project on retail sales data.
- Feature engineering: temporal signals, revenue metrics, one-hot encoding
- **Random Forest** regression model with MAE / R² evaluation
- Automated chart generation (category sales, profit margins, monthly trend)
- **Stack:** Python · pandas · scikit-learn · matplotlib · seaborn

### [AdventureWorks Data Warehouse](https://github.com/tallal85/adventureworks-data-warehouse)
A full **data warehouse** built on the AdventureWorks dataset following medallion architecture principles.
- Bronze → Silver → Gold layer transformations
- Star-schema dimensional model (fact & dimension tables)
- Analytical SQL queries for business intelligence reporting
- **Stack:** SQL · Data Modeling · BI

### [SQL Scripts Collection](https://github.com/tallal85/sql-scripts-collection)
A curated library of **SQL scripts** ranging from fundamentals to advanced patterns.
- Window functions, subqueries, and CTEs
- Indexing strategies and query performance optimization
- Practical examples from **data engineering and analytics workflows**
- **Stack:** SQL · PostgreSQL · T-SQL
